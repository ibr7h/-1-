# Operational Plan PWA v2 — خريطة الشاشات

## الهدف
تحويل النظام التشغيلي الحالي إلى تطبيق PWA متعدد المدارس مع الحفاظ على قالب الطباعة الحالي كمرجع ثابت لا يتأثر بتغييرات واجهة الاستخدام.

## مبادئ الواجهة
- الواجهة اليومية ليست نسخة A4 مصغرة؛ بل واجهة إدارة سهلة للجوال والكمبيوتر.
- شاشة الطباعة مستقلة عن شاشة التحرير.
- التنقل السفلي للجوال: الرئيسية — الخطط — التقويم — الطباعة — الإعدادات.
- على الكمبيوتر يتحول التنقل إلى Sidebar.
- المدرسة النشطة تظهر دائمًا في أعلى التطبيق مع إمكانية التبديل بينها.

## S0 — شاشة البدء
### الحالة الجديدة
تظهر عندما لا توجد مدارس محفوظة.

### العناصر
- شعار التطبيق.
- عنوان: النظام التشغيلي المدرسي.
- زر: إنشاء مدرسة جديدة.
- زر: استيراد نسخة احتياطية.
- إشارة إلى أن التطبيق يعمل دون اتصال بعد التثبيت.

## S1 — معالج إنشاء مدرسة
معالج خطوة بخطوة بدل نموذج طويل.

### الخطوة 1: بيانات المدرسة
- اسم المدرسة.
- نوع المدرسة: ابتدائي / متوسط / ثانوي / مجمع / أخرى.
- المنطقة التعليمية.
- الإدارة / المكتب.
- الشعار.
- رمز QR اختياري.

### الخطوة 2: العام والخطة
- العام الدراسي هجريًا.
- الفصل / الفترة.
- تاريخ بداية الدراسة.
- عدد الأسابيع.

### الخطوة 3: المسؤولون
- مدير المدرسة.
- وكيل شؤون المعلمين.
- وكيل الشؤون التعليمية.
- المشرف، عند الحاجة.

### الخطوة 4: التقويم
- الإجازات الرسمية.
- المناسبات.
- فترات الاختبارات.
- إمكانية إضافة حدث يدوي.

### الخطوة 5: المعاينة
- ملخص البيانات.
- زر: إنشاء الخطة.

## S2 — الرئيسية Dashboard
### أعلى الشاشة
- المدرسة النشطة.
- العام الدراسي والفصل الحالي.
- زر تبديل المدرسة.

### بطاقات المؤشرات
- الأسبوع الحالي.
- عدد الأسابيع الكلي.
- الإجازة / المناسبة القادمة.
- آخر تعديل على الخطة.
- حالة الطباعة: جاهزة.

### إجراءات سريعة
- فتح الخطة.
- إضافة خطة.
- تعديل المدرسة.
- معاينة الطباعة.
- تصدير نسخة احتياطية.

## S3 — قائمة المدارس
### الوظائف
- عرض جميع المدارس المحفوظة.
- اختيار المدرسة النشطة.
- إضافة مدرسة.
- نسخ مدرسة مع إعداداتها.
- أرشفة مدرسة.
- حذف مدرسة بعد تأكيد واضح.

### ملاحظة
حذف مدرسة لا يجب أن يحذف النسخة الاحتياطية المصدرة خارجيًا.

## S4 — الخطط
### قائمة الخطط الخاصة بالمدرسة النشطة
كل بطاقة خطة تعرض:
- اسم الخطة.
- العام الدراسي.
- الفصل / الفترة.
- عدد الأسابيع.
- آخر تحديث.
- الحالة: مسودة / نشطة / مؤرشفة.

### الإجراءات
- فتح.
- نسخ.
- إعادة تسمية.
- أرشفة.
- معاينة الطباعة.

## S5 — محرر الخطة
### التصميم
شبكة بطاقات أسابيع سهلة اللمس وليست صفحة A4.

### بطاقة الأسبوع
- رقم الأسبوع.
- التاريخ من / إلى.
- أيام الدوام.
- المناسبة أو الإجازة إن وجدت.
- حالة الأيام.
- ملاحظات.

### الإجراءات
- تعديل الأسبوع.
- إضافة حدث.
- إعادة حساب التواريخ من أسبوع محدد.
- استعادة القيم التلقائية.

## S6 — التقويم
### طرق العرض
- قائمة أحداث.
- عرض شهري مبسط.

### أنواع الأحداث
- إجازة.
- مناسبة وطنية.
- اختبارات.
- تعليق دراسة.
- حدث مخصص.

### خصائص الحدث
- الاسم.
- تاريخ البداية والنهاية.
- النوع.
- هل يظهر داخل بطاقة الأسبوع؟
- هل يظهر كشريط مستقل في الطباعة؟
- ترتيب الأولوية عند وجود أكثر من حدث.

## S7 — الطباعة
هذه الشاشة هي الجسر الوحيد إلى قالب الطباعة المعتمد.

### الخيارات
- الفترة الأولى.
- الفترة الثانية.
- الفترتان.
- نسخة رسمية.
- نسخة تفاعلية، إذا لزم.

### الأزرار
- معاينة A4.
- طباعة.
- PDF نظيف مستقبلًا.

### قاعدة ثابتة
لا يتم تعديل قياسات قالب الطباعة أو شبكة الأسابيع أو تنسيق التوقيعات من هذه الشاشة.

## S8 — إعدادات المدرسة
### تبويب: البيانات الأساسية
- اسم المدرسة.
- المرحلة.
- المنطقة.
- الإدارة.
- الشعار.
- QR.

### تبويب: المسؤولون
- المدير.
- الوكلاء.
- المشرف.
- مسميات الوظائف.

### تبويب: الطباعة
يسمح فقط بتغيير البيانات، وليس CSS أو أبعاد A4.

## S9 — إعدادات التطبيق
إعدادات عامة لا ترتبط بمدرسة واحدة:
- الوضع الفاتح / الداكن مستقبلًا.
- حجم واجهة التطبيق.
- المدرسة الافتراضية عند التشغيل.
- تفضيلات التاريخ: هجري / ميلادي / كلاهما.
- النسخ الاحتياطي.
- معلومات الإصدار.

## S10 — النسخ الاحتياطي والاستعادة
### تصدير
ملف JSON واحد يحتوي على:
- المدارس.
- الخطط.
- الأسابيع.
- الأحداث.
- المسؤولين.
- الإعدادات العامة.

### استيراد
- فحص نسخة الملف قبل الاستيراد.
- إظهار ملخص لما سيتم استيراده.
- عدم الكتابة فوق البيانات الحالية إلا بعد موافقة المستخدم.

## تدفق الاستخدام الرئيسي
1. إنشاء مدرسة أو اختيار مدرسة موجودة.
2. إنشاء خطة أو فتح خطة حالية.
3. إدارة الأسابيع والتقويم من واجهة الجوال.
4. فتح شاشة الطباعة.
5. تمرير البيانات إلى قالب الطباعة الثابت.
6. الطباعة دون تغيير بنية القالب.

## التنقل المقترح
### الجوال
الرئيسية | الخطط | التقويم | الطباعة | الإعدادات

### الكمبيوتر
Sidebar بنفس الأقسام مع قائمة المدارس أعلى الشريط.
