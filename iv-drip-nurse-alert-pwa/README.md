# IV Drip Nurse Alert PWA

نسخة PWA محسّنة من صفحة نظام متابعة وتنبيه المحاليل الوريدية.

## التحسينات
- Web App Manifest وService Worker وأيقونات PWA.
- دعم التثبيت على Android وiOS عبر Add to Home Screen.
- تخزين App Shell محليًا، مع تخزين Tailwind بعد أول تشغيل متصل.
- آلية تحديث Service Worker وزر تحديث داخل التطبيق.
- إشعارات نظام بعد منح الإذن عندما يكون التطبيق قادرًا على تنفيذ منطق المؤقت.
- Screen Wake Lock اختياري لإبقاء شاشة محطة التمريض مستيقظة.
- استبدال Tone.js بـWeb Audio API.
- إصلاح إعادة حساب التنبيه المبكر بعد تمديد 15 دقيقة.
- إصلاح اختيار 100/1000 مل.
- ترميز المدخلات قبل عرضها لتقليل مخاطر XSS.
- تقليل كشف بيانات المريض في إشعارات النظام.

## قيد سريري مهم
هذا المشروع أداة مساعدة/نموذج أولي وليس جهازًا طبيًا معتمدًا.
مؤقت JavaScript داخل PWA لا يضمن التنبيه في موعده إذا أغلق النظام التطبيق أو علّقه في الخلفية.
للتنبيه الموثوق أثناء الإغلاق يلزم Push Notifications من خادم موثوق أو تطبيق أصلي مناسب ومتوافق مع سياسات المنشأة.
